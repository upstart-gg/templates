# Minimal template

## Purpose
This template is meant to be a clean slate for building your app without any unnecessary code or features.
It includes only the essential files and configurations needed to get started.

## Contents

### Routes
- A layout (`app/routes/_layout.tsx`) for the homepage and future routes
- A homepage (`app/routes/_layout._index.tsx`) displaying a placeholder (should be replaced by the actual homepage)
- A 404 page (`app/routes/$.tsx`) - Don't edit or remove this file

### Components
- A `SkeletonTemplate` component that displays a temporary placeholder while using the app for the first time (should be removed once the homepage is implemented). It is not a layout to reproduce: the site's design comes from its Design Brief (`docs/DESIGN.md`)

### Themes
- A light and a dark theme (`app/config/themes/default-light.json` and `app/config/themes/default-dark.json`), meant to be restyled to the site's Design Brief (colors, fonts, radius)

---

**IMPORTANT**: This template is meant to be a starting point. You should update or remove any code that is not needed and implement the actual features of your app.
